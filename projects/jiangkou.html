Cultural visual / Personal competition entry

江口
沉银

从“沉没、发现、重见”提炼叙事，将器物建模、材质灯光与包装延展组织为一组有历史重量的文化视觉提案。

RoleConcept / 3D / Packaging
TeamPersonal project / Individual execution
Output3D visual / Packaging
Year2024

01 / Context

让器物不只被展示，
也成为叙事入口。

项目不把历史元素直接贴到画面上，而是通过器物的尺度、金属表面、低照度环境与包装语言，建立“水下发现”到“重新被看见”的观看路径。

Personal concept / Non-official cultural visual proposal

My contribution概念设定、器物建模与视觉延展
3D contribution材质、灯光、场景与产品渲染
Output boundary个人文化视觉概念，不代表官方合作
Design focus历史叙事与当代产品构图
02 / DirectionThree visual decisions
01 / Object器物先成为主角

以简洁、克制的构图建立器物的重量与比例，让文化信息从形体与表面开始被理解。

02 / Light低照度里的金属反光

用冷暗空间与少量暖色边缘光模拟被打捞、被发现时的视觉情绪，而非制造装饰性特效。

03 / Extension从场景到包装

将同一套材质、色彩和构图规则延展到包装与传播画面，使项目具备实际应用的可读性。

03 / 3D visual system

把发现的瞬间，
转译成可观看的空间。

模型、材质和环境并不是独立的效果层；它们共同服务于器物从沉没到重见的叙事。

04 / Reflection

文化视觉的当代感，
来自取舍而非堆叠。

这组练习强化了我在三维场景中控制材质、光线与产品构图的能力，也让我更明确地将文化元素作为叙事依据，而不是表面装饰。

Strength器物建模、材质表现与场景叙事

Role fit文化视觉、产品渲染与品牌体验

Project status个人概念项目，非官方合作
