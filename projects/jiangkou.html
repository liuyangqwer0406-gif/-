Cultural visual / Competition finalist · 2024

江口
沉银

我以“沉没、发现、重见”为观看顺序，独立完成器物建模、金属材质、低照度场景与文创包装；项目入围 2024 眉山江口沉银博物馆文创设计大赛。

RoleConcept / 3D / Packaging
TeamPersonal project / Individual execution
Output3D visual / Packaging
Year2024

01 / Context

先让器物被看清，
再让历史被感知。

我没有直接堆叠传统纹样，而是把“西王赏功”钱币及香炉作为视觉中心：控制器物尺度、金属反光和环境亮度，让观众先读到形体，再沿着水下发现的线索进入历史语境。

Competition finalist / Personal work / Non-official proposal

My contribution概念设定、器物建模与包装延展
3D contribution材质、灯光、场景与产品渲染
Result2024 文创设计大赛入围
Output boundary个人提案，不代表官方合作
02 / DirectionThree visual decisions
01 / Object器物先成为主角

减少背景信息，用正面、侧面与使用场景交代比例，让形体本身承担第一层文化识别。

02 / Light用反光提示“被发现”

冷暗环境压低背景，少量暖色边缘光勾出金属轮廓，模拟器物从水下进入视线的瞬间。

03 / Extension包装沿用观看顺序

包装继续使用器物特写、暗色底与局部金属色，让展示画面与实际文创载体保持连续。

03 / 3D visual system

用模型、材质与光线，
还原一次发现过程。

建模先保证器物比例，金属材质负责年代感，环境光则控制信息出现的顺序；三者共同完成从沉没到重见的观看路径。

04 / Reflection

文化元素越重要，
越需要克制使用。

这次实践让我确认：历史感不来自纹样数量，而来自器物是否准确、光线是否有依据、观看顺序是否清楚。减少装饰后，建模和产品构图反而更有说服力。
