Esports event identity / Graduation concept

RUNES符文攻防战

红蓝阵营承担远距离识别，五类符文负责内容编码；我把同一套规则应用到主视觉、户外立面、空间导视、票证与赛事周边。

RoleVisual identity / Art direction
TeamGraduation project / Individual concept
OutputKV / Wayfinding / Merchandise
Year2026

01 / Context

一场赛事需要的不只是海报，
还要让观众找到阵营与方向。

我把观众路径拆成三个尺度：远处先看见红蓝对抗，靠近后通过符文识别内容类型，进入场地后再由区域编码和导视完成行动。票证与周边继续沿用同一规则。

Unofficial graduation concept / Not affiliated with Riot Games

Direction活动概念与视觉规则
Identity标志、符文图标、色彩与纹理
Application户外、导视、票证与周边
Boundary非官方毕业设计概念
02 / StrategyThree system decisions
01 / Faction先看见红蓝对抗

构图、光线与空间分割始终围绕两方展开，使阵营在户外大画面和小尺寸票证上都能快速区分。

02 / Rune再用五类符文编码

精密、主宰、巫术、坚决与启迪分别对应色彩、图标和资源标识，用于分类信息而不是单纯装饰。

03 / Venue最后进入场地动线

区域编号、方向箭头和阵营色被放进立面与导视，检验这套识别能否真正帮助观众行动。

03 / Identity system

同一套编码，
在不同尺度继续工作。

主视觉制造对抗张力，符文图标区分内容，导视负责行动，周边负责长期识别；每种应用都保留红蓝阵营和五类符文两层信息。

04 / Extended boards

补充毕业设计中的系统展板，让品牌标志、色彩变体、导视规则、主视觉与活动应用能以完整的项目语境被阅读。点击任意图片可查看大图。

05 / Reflection

情绪负责吸引，
编码负责让现场可用。

这次毕业设计把我从单张主视觉带到完整活动应用。最重要的收获不是做出更多物料，而是让阵营、类别和方向在不同尺寸中仍有明确优先级。
