Esports event identity / Graduation project

RUNES符文攻防战

围绕红蓝阵营对抗建立电竞活动视觉系统，把符文类别、阵营冲突与赛事节奏转化为可用于屏幕、户外、空间和周边的识别语言。

RoleVisual identity / Art direction
TypeGraduation concept
OutputKV / Wayfinding / Merchandise
Year2026

01 / Context

把游戏世界观，
转译成现场识别系统。

项目不是对单张电竞海报的练习，而是从活动品牌角度思考完整体验：观众需要在远距离识别阵营，在场地中找到方向，也要在票证、周边与数字界面中持续感受到同一个世界。

Unofficial graduation concept / Not affiliated with Riot Games

Direction活动概念与视觉系统
Identity标志、符文图标、色彩与纹理
Application户外、导视、票证与周边
Boundary非官方毕业设计概念
02 / StrategyThree system decisions
01 / Faction对抗先于装饰

红蓝阵营是最直接的阅读入口，构图、光线和空间分割都围绕双方冲突建立。

02 / Rune五类符文编码

将精密、主宰、巫术、坚决与启迪转译为对应色彩、图标和资源标识，形成可扩展的视觉语法。

03 / Venue进入真实场地

从屏幕主视觉延展到户外立面、导视和周边，使识别系统能够支持完整的赛事现场体验。

03 / Identity system

一套能持续生长的
赛事视觉语法。

色彩与符文图标负责快速分类，主视觉负责情绪，导视和周边则检验系统在不同尺度上的一致性。

04 / Extended boards

补充毕业设计中的系统展板，让品牌标志、色彩变体、导视规则、主视觉与活动应用能以完整的项目语境被阅读。点击任意图片可查看大图。

05 / Reflection

活动视觉必须
同时解决情绪与秩序。

这个项目让我把品牌识别、平面延展和空间应用放在同一套规则里思考。强烈的视觉冲击负责吸引观众，清晰的编码与层级则保证系统真正可用。

Strength从主视觉到空间导视的完整延展

Role fit活动视觉、电竞视觉与品牌体验岗位

Next iteration补充动态开场、比赛信息界面与现场动线原型
