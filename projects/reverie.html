Immersive web experience / Personal project

REVERIE

为流动式实验艺术机构构建数字叙事体验，以森林入口、作品世界索引和中英双语内容建立一个可探索的品牌空间。

RoleConcept / Web / Interaction
TeamPersonal project / Individual execution
OutputResponsive site / WebGL
Year2026
Open live website ↗

01 / Context

把网站做成入口，
而不是作品清单。

REVERIE 的核心不是展示固定展厅，而是建立一个不断变化的艺术世界。首页以森林遗迹作为入口，用户通过“坠入”动作进入内容，随后在不同世界、工坊与档案之间探索。

Designed and built as a personal web project / Live link available

Concept品牌世界观与内容结构
Interface桌面与移动端视觉设计
Interaction入口、索引与滚动反馈
Build响应式网页与WebGL体验
02 / ExperienceThree interaction decisions
01 / Portal入口即叙事

用完整森林场景取代常规标题页，让第一屏直接建立机构的神秘感与世界观。

02 / Archive作品成为世界

将项目组织为可探索的“世界”与档案，而不是标准卡片列表，使内容结构与品牌概念一致。

03 / Responsive移动端重新编排

在窄屏上保留氛围与关键路径，同时重组导航、文字和图像比例，避免简单缩小桌面页面。

03 / Interface

图像、文字与交互
共同建立世界观。

页面以大幅环境图像承担情绪，细小双语导航提供秩序，卡片与移动端模块则承接更具体的内容访问。

04 / Reflection

设计语言需要
被交互真正承接。

这个项目证明我不仅能完成静态视觉，也能把品牌气质转换为页面结构、滚动节奏和响应式体验。设计与实现同步推进，使概念不会在落地阶段被削弱。
