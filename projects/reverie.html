Immersive web experience / Personal project

REVERIE

我独立设计并实现一座线上艺术机构：用户从 WebGL 森林入口进入，再访问作品世界、工坊与档案；中英双语内容和移动端布局均按浏览路径重新组织。

RoleConcept / Web / Interaction
TeamPersonal project / Individual execution
OutputResponsive site / WebGL
Year2026
Open live website ↗

01 / Context

把网站做成入口，
而不是作品清单。

常规机构网站从导航和项目列表开始，REVERIE 则先让用户进入环境。森林遗迹负责建立情绪，“坠入”动作完成场景切换，之后才逐步开放作品世界、工坊与档案。

Designed and built as a personal web project / Live link available

Concept品牌世界观与内容结构
Interface桌面与移动端视觉设计
Interaction入口、索引与滚动反馈
Build响应式网页与 WebGL 实现
02 / ExperienceThree interaction decisions
01 / Portal第一屏先建立场所感

森林场景取代常规标题页，机构名称与入口动作后置，让环境先定义观看情绪。

02 / Archive项目按“世界”组织

作品不进入统一卡片，而是按世界、工坊与档案分层，让内容分类本身延续机构设定。

03 / Responsive移动端重新安排路径

窄屏减少同时出现的信息，优先保留入口、当前位置和下一步操作，而不是缩小桌面构图。

03 / Interface

环境负责吸引，
索引负责带路。

大幅图像控制情绪，双语导航标记位置，作品索引和移动端模块承担具体访问；每一层只解决一种阅读任务。

04 / Reflection

气质写在画面里，
路径写在交互里。

独立完成设计与实现，让我能直接检验每个视觉决定是否支持浏览：入口是否明确、索引是否可理解、移动端是否仍保留关键氛围。无法被使用的效果会在开发阶段被删掉。
